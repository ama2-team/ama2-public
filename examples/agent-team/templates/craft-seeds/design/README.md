# Design — craft seed

A starting craft playbook for an agent-team **design** worker. Adapted from
[knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)
(Apache-2.0 — see [../../CREDITS.md](../../CREDITS.md)).

These are **starting material, not final**: when the Manager adds a `design`
member with this seed, the member reads these skills during `self-onboard` and
**fits them to its own mandate**, then keeps sharpening them via `self-improve`.

## Skills (methodology)

- `accessibility-review` — Run a WCAG 2.1 AA accessibility audit on a design or page.
- `design-critique` — Get structured design feedback on usability, hierarchy, and consistency.
- `design-handoff` — Generate developer handoff specs from a design.
- `design-system` — Audit, document, or extend your design system.
- `research-synthesis` — Synthesize user research into themes, insights, and recommendations.
- `user-research` — Plan, conduct, and synthesize user research.
- `ux-copy` — Write or review UX copy — microcopy, error messages, empty states, CTAs.

## Connectors

`.mcp.json` + `CONNECTORS.md` list example MCP connectors for this role. They are
**examples — edit them to your own stack** (connect the tools your team actually
uses). A member proposes the connectors it needs; the owner approves and wires them.
